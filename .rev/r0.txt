One design note worth a look before release: the restart error tells users to recover via `from_snapshot(...)`, but a snapshot taken after `stop()` carries `status: "stopped"`, so the restored interpreter also refuses to start — the suggested recovery path is a dead end (verified; `current_state_ids` reads live while `send()` is silently dropped).
